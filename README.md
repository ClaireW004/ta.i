# ta.i

This website will take in lecture material like google slides, powerpoint, etc. and will comphrehend all the slides. It will then based on voice input and give suggestions that can only be shared on the presenters screen (ie when screen shared it won't show these suggestions). It will also have two other agents, one agent to pace the speed of how fast the presenter is going (ie if they are pacing too fast it will give them a warning to slow down or speed up when they are pacing too slow) and another agent for focus of the slides (ie when the presenter starts talking about their pets when it has nothing to do with the slides it will give a warning).
